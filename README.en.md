# Binary to Decimal CLI (b2d)

# Information
The binary system is the number system on which all digital computers are based. Therefore, it is important to understand binary mathematics, or base-2 arithmetic.

# Objective
B2D is designed to provide practice and insight into how binary calculations work. It allows the user to enter sequences of up to 8 binary digits—0s
and 1s—in any order, and then displays their decimal equivalent.

This challenge requires implementation with the following constraints:
-   Arrays may not be used to store the binary digits entered by the user
-   The decimal equivalent of a given binary digit in the
    sequence must be calculated using a single mathematical function, such as
    the natural logarithm.

## Implementation

-   [ ] Allow the entry of up to 8 binary digits in a single input field
-   [ ] Issue a notification if any value other than `0` or `1` is entered
-   [ ] Display the results in a single output field containing the decimal (base 10) equivalent of the entered binary number
