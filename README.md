# Binary to Decimal CLI (b2d)

# Informação
O sistema binário é o sistema numérico no qual todos os computadores digitais se baseiam. Portanto, é importante se compreenda a matemática binária, ou de base 2.

# Objetivo
O B2D é proporcionar prática e compreensão sobre como funcionam os cálculos binários. Que permite o usuário insira sequências de até 8 dígitos binários, 0's
e 1's, em qualquer ordem, e, em seguida, exibe seu equivalente decimal.

Este desafio exige implementar com estas restrições:
-   Não é permitido usar matrizes para armazenar os dígitos binários inseridos pelo usuário
-   A determinação do equivalente decimal de um determinado dígito binário na
    sequência deve ser calculada usando uma única função matemática, por
    exemplo, o logaritmo natural.

## Desenvolvimento

-   [ ] Inserir até 8 dígitos binários em um único campo de entrada
-   [ ] Notificar caso inserido qualquer valor que não seja `0` ou `1`
-   [ ] Visualizar os resultados em um único campo de saída contendo o equivalente decimal (base 10) do número binário inserido


## Recursos adicionais

-   [ ] Inserir um número variável de dígitos binários
